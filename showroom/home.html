How I got here

1987 to now.

The first programs were BASIC, on a small machine in a room in Brazil. Then C, and C++ when the projects outgrew a single file. Those years taught me what the machine actually does, which is still the part of the work I trust most.

Software engineering became the formal trade. The web became the place I practise it: HTML and CSS first, then JavaScript, then PHP and Python behind them, then SQL for whatever has to be remembered.
